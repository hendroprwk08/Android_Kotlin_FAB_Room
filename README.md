# Android Kotlin FAB Room

Android Kotlin dengan komponen FAB, berbasis data lokal ROOM

## Deskripsi

Proyek ini adalah aplikasi Android yang dibangun menggunakan **Kotlin** dengan fitur-fitur berikut:

- **FAB (Floating Action Button)**: Komponen UI yang responsif dan interaktif
- **ROOM Database**: Penyimpanan data lokal yang aman dan efisien
- Arsitektur modern untuk aplikasi Android

## Teknologi

- **Bahasa**: Kotlin 100%
- **Database**: Android ROOM
- **UI Components**: Floating Action Button (FAB)

## Fitur Utama

- Manajemen data lokal menggunakan ROOM Database
- Interface yang user-friendly dengan FAB
- Operasi CRUD (Create, Read, Update, Delete) untuk data

## Instalasi

1. Clone repository ini:
```bash
git clone https://github.com/hendroprwk08/Android_Kotlin_FAB_Room.git
```

2. Buka project di Android Studio
3. Sinkronkan Gradle dependencies
4. Jalankan aplikasi di emulator atau device Android
